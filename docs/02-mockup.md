## Screens

### 1. Dashboard / Home

This is the first screen the user sees after opening ResortBook. It provides an overview of the resort and gives the user access to the main reservation functions.

* **Add Reservation** → Opens the **Add Reservation** screen.
* **View Reservations** → Opens the **Reservation List**.
* **View Calendar** → Opens the **Calendar** screen.

### 2. Add Reservation

This screen allows staff to create a new reservation by entering the required guest and booking information.

After the reservation is submitted, the user can return to the reservation list and view the newly created booking.

### 3. Reservation List

This screen displays the existing reservations stored in the application.

* Selecting a reservation → Opens the **Reservation Details** screen.
* The user can browse or search reservations to locate a specific booking.

### 4. Reservation Details

This screen displays the information belonging to the reservation selected from the Reservation List.

It allows staff to review the guest and reservation information before returning to the reservation list or continuing with other reservation-management tasks.

### 5. Calendar

This screen provides a calendar-based view of reservations according to their scheduled dates. It allows staff to visually check when reservations are taking place and helps with room availability planning.

The Calendar can be accessed from the Dashboard / Home screen.

### Navigation Flow

The primary ResortBook navigation flow is:

**Dashboard / Home**
→ **Add Reservation**
→ **Reservation List**
→ **Reservation Details**
→ **Calendar**

The same navigation flow and core functionality apply to both the **mobile and desktop viewports**.
